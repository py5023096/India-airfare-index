The problem

Airfares move faster than the surveys that measure them.

Dynamic pricing means the same route can cost 40% more within a day. Periodic manual collection for CPI can't keep pace with that volatility — so the transport sub-index lags reality.

How it works

From a fare on a screen to a published index point.

Four stages, running continuously across every route in the basket.

01

Collect

Fares pulled from airline and OTA sites via APIs where available, headless-browser scraping otherwise.

02

Clean

Duplicate listings and glitch fares removed; base fare separated from taxes and surcharges.

03

Weight

Route-level fares combined using DGCA passenger-traffic shares, adjusted for seasonality.

04

Publish

Index value and route breakdown pushed to the dashboard and made available to CPI systems.
